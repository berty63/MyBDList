# MyBDList

Application Android personnelle pour gérer une collection de bandes dessinées.

## Fonctionnalités prévues
- Ajouter des BD par scan ISBN/EAN
- Organiser les albums par série, auteur et tome
- Afficher les couvertures
- Identifier les tomes manquants
- Importer une collection BDGest
- Reconnaître des BD à partir d'une photo des tranches

## Technologies envisagées
- Kotlin
- Android Studio
- Room / SQLite
